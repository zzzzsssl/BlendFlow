# Changelog

## 0.6.3 — Initial public package

- Four collapsible sidebar sections: Smart Inspector, Smart Thumb Preview, Export Guard and Smart Render.
- Scene issue categories, object selection and explicit resolution actions.
- Thumbnail framing, four camera angles, three studio lighting presets and exposure control.
- FBX/GLB export, editable platform presets, smoothing, supported object animation and JSON reports.
- Cycles 512/1024/2048 sample comparison with a 4096 reference and multi-aspect composition previews.
- Registration cleanup and deferred initialization for Blender's restricted enable phase.

Experimental release. See README.md and TESTING.md for scope and limitations.
